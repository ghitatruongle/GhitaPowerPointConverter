# Piano nâng cấp Ghita PPT Converter lên v0.1.5

## Tổng quan dự án
Ứng dụng Flutter Windows (ghita_ppt_converter) — trình chuyển HTML sang PPTX có tích hợp AI Chat, quản lý slide, hiệu ứng chuyển slide, và theme Light/Dark/System. Hiện tại ở v0.0.5.

---

## Các commit sẽ thực hiện

### Commit 1 — Multi-model provider configuration
**Mục tiêu:** Mỗi provider có thể cấu hình nhiều model, người dùng chọn model khi dùng.

- **`AIProviderConfig`**: thêm trường `List<String> availableModels` và `String selectedModel`; xóa trường `model` đơn lẻ
- **`providers.json`**: cập nhật template mặc định (OpenAI: gpt-4o, gpt-4o-mini, gpt-3.5-turbo, o1-preview; Anthropic: claude-3-5-sonnet, claude-3-opus, claude-3-haiku)
- **`AIProviderManager`**: cập nhật `addProvider`, `updateProvider` xử lý danh sách models; API calls dùng `selectedModel`
- **`ConfigService`**: lưu/tải `availableModels` và `selectedModel`
- **UI**: Provider Settings dialog → thêm quản lý danh sách models (thêm/xóa model), dropdown chọn model active

### Commit 2 — Pre-made HTML template system
**Mục tiêu:** Thêm mẫu HTML sẵn có, đi kèm hiệu ứng chuyển slide.

- **Tạo 5 templates** trong `assets/templates/`:
  - `business.html` — trình bày kinh doanh (xanh dương chuyên nghiệp)
  - `creative.html` — sáng tạo (màu sắc, hiện đại)
  - `academic.html` — học thuật (sạch, trang trọng)
  - `marketing.html` — tiếp thị (tự tin, thu hút)
  - `minimal.html` — tối giản (trắng đơn sắc)
- **`lib/models/slide_template.dart`**: model `SlideTemplate` (name, description, htmlContent, recommendedEffect, icon)
- **`lib/services/template_service.dart`**: đọc templates từ assets, parse metadata, expose danh sách
- **UI**: thêm button "Templates" trên màn hình HTML to PPT → mở dialog gallery xem trước và áp dụng template; template áp dụng → tự động set hiệu ứng chuyển slide tương ứng

### Commit 3 — Export to HTML
**Mục tiêu:** Xuất ra file HTML có thể trình bày trên trình duyệt hoặc trong app.

- **`lib/services/html_export_service.dart`**: tạo file HTML tự chứa (self-contained)
  - CSS nhúng cho styling slide
  - JS nhúng cho điều hướng (prev/next, phím mũi tên, space)
  - Mỗi slide là một `<section>`, đi kèm thanh tiến trình và nút điều hướng
  - Tự động lấy màu nền từ `data-bg-color`
- **`PresentationState`**: thêm `exportToHtml(fileName)` → gọi service lưu vào Documents
- **UI**: cập nhật export dialog → chọn định dạng (PPTX / HTML), thay thế dialog cũ

### Commit 4 — UI/UX upgrade
**Mục tiêu:** Nâng cấp giao diện trải nghiệm toàn app.

- **Theme**: cải thiện color scheme (accent màu đỏ đô `Colors.deepOrange`, card elevation tốt hơn, divider, ripple effect)
- **HomeScreen**: AppBar có gradient, icon tốt hơn, bottom nav có indicator animation
- **HtmlToPPTScreen**: 
  - Card layout chia 2 cột (editor trái, slide list phải) thay vì stack dọc
  - Slide thumbnails đẹp hơn (icon-based summary thay vì text chips nhỏ)
  - Export button có dropdown chọn format
  - Template gallery accessible từ header
- **AiChatScreen**: 
  - Provider header card đẹp hơn với avatar icon theo provider
  - Message bubbles có animation nhẹ
  - Model selector hiển thị trong header
- **EffectsScreen**: 
  - Grid layout cho animation options thay vì dropdown đơn
  - Visual effect chips thành actionable cards

### Commit 5 — Error handling & performance
**Mục tiêu:** Ít lỗi hơn, hiệu năng tốt hơn.

- **Error handling**: 
  - Wrapper `safeCall` cho async operations với SnackBar thông báo lỗi thân thiện
  - Validation mạnh hơn cho HTML input, API key, model name
  - Network error messages rõ ràng (timeout, 401, 429, 500)
  - Null-safety audit các `!` operators
- **Performance**:
  - `const` constructors tối đa
  - `ListView.builder` với `itemExtent` cho slide list
  - Lazy template loading (chỉ load khi mở gallery)
  - Debounce text input (500ms) cho preview updates

### Commit 6 — Version bump, tests, polish
**Mục tiêu:** Chuẩn bị release v0.1.5.

- **pubspec.yaml**: `version: 0.1.5+1`
- **Tests**: thêm unit tests cho `SlideTemplate`, `TemplateService`, `HtmlExportService`, multi-model provider config
- **README.md**: cập nhật phiên bản, thêm hướng dẫn templates và HTML export
- **assets/templates/**: đăng ký trong pubspec.yaml
- **Cleanup**: loại bỏ debug prints, sắp xếp imports
