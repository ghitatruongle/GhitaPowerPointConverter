## 🚀 Upgrade Plan: Ghita PPT Converter v0.0.5 — Major Upgrade

### Overview
Transform the app from a functional prototype into a polished, feature-rich presentation tool with professional PPTX output, smarter AI integration, and a delightful user experience.

---

### 1. 🐛 CRITICAL BUG FIXES (EffectsScreen)

| # | Issue | Fix |
|---|-------|-----|
| 1.1 | `_availableAnimations` undefined — `_availableEffects` is the real variable | Rename to `_availableAnimations` or align code to use `_availableEffects` with proper display labels |
| 1.2 | `_selectedEffect.name = newValue` — cannot mutate Dart enum | Replace with a `String _selectedAnimationName` field for the preview; keep `SlideEffect` separate for PPTX export |
| 1.3 | Switch cases use display strings (`'Fade In'`) but enum values are `SlideEffect.fade` | Use enum values directly; maintain display name mapping via a helper function |
| 1.4 | Transition XML in PPTGenerator uses fixed 500ms (`dur` typo — should be `dur`? check OOXML spec) | Verify against OOXML: `<p:transition>` uses `spd` (slow/medium/fast), not a `dur` attribute on child — fix to valid PPTX XML |

---

### 2. 📊 PPTX ENGINE UPGRADE (ppt_generator.dart)

| # | Feature | Details |
|---|---------|---------|
| 2.1 | **Widescreen 16:9** | Change from `type="screen4x3"` (9144000x6858000) to `type="screen16x9"` (12192000x6858000 EMUs) |
| 2.2 | **Proper bullet lists** | `<a:buChar>` for unordered, `<a:buAutoNum>` for ordered lists in `<a:pPr>` |
| 2.3 | **Table support** | Parse `<table>` → generate `p:graphicFrame` with `a:tbl` for rows/cells; handle `<th>`, `<td>`, basic borders |
| 2.4 | **Image embedding** | Support `<img>` tags: download/copy image, add to media/ folder in ZIP, reference via `r:embed` + relationship in slide XML |
| 2.5 | **Multi-line list items** | Proper `<a:br/>` handling within runs for line breaks in lists |
| 2.6 | **Slide background color** | Optional `data-bg-color` attribute on HTML or a presentation-level setting |
| 2.7 | **Subtitle support** | If `<h2>` present, render as subtitle text box below title |

### 3. 📝 SLIDE MANAGEMENT (html_to_ppt_screen.dart & presentation_state.dart)

### 4. 🤖 AI ENHANCEMENTS (ai_chat_screen.dart & ai_provider_manager.dart)
