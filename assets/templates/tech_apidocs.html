API Reference

v2.0 Endpoints & Authentication

GET    /api/v2/users         # List all users
POST   /api/v2/users         # Create new user
PUT    /api/v2/users/:id     # Update user
DELETE /api/v2/users/:id     # Remove user

GET    /api/v2/analytics     # Fetch analytics
POST   /api/v2/webhooks      # Register webhook

Auth: Bearer <token>  |  Rate Limit: 1000 req/min
